Spine Analyzer Tools

脊椎X線画像から計測値を算出するローカルWebアプリ集です。用途に応じてツールを選んでください。

Spinopelvic Analyzer

PI / PT / SS / LL / SVA を計測。左右大腿骨頭・S1・L1（任意でC7）のランドマークから脊椎骨盤パラメータを算出します。

開く →

Cervical Analyzer

C2-C7 Cobb角 / T1 Slope / C2-C7 SVA を計測。C2・C7・T1のランドマークから頚椎アライメントパラメータを算出します。

開く →

画像は端末外に送信されず、すべてブラウザ内で処理されます（ローカル処理）。
